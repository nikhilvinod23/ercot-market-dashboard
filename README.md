# ERCOT Market Pulse

An isolated, dependency-free dashboard interface prototype for tracking the ERCOT market.

## Current scope

- Responsive dashboard shell with market-operations visual language
- Summary cards for demand, real-time pricing, renewable share, and available capacity
- Illustrative real-time price trend
- Illustrative generation mix and demand outlook
- Market alerts/watchlist surface
- Lightweight interactions for navigation, chart range controls, refresh, and informational toasts

## Important note

This prototype does not connect to ERCOT or any other data source. All values and alerts are illustrative placeholders intended to establish the interface and information hierarchy.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.
