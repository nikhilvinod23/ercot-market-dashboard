## Methodology

Latest source-posted forecast before 00:00 Central Time on the delivery day; source-designated day-ahead display series used only when an issued vintage is unavailable.

RT settlement point prices at native 15-minute intervals; hourly means require four intervals for event detection. DAM is hourly. Latest RT cards compare their native interval against the containing DAM hour.

Issued and collected times are separate. First collection time is retained. Source-posted historical forecasts are not proof that this project captured them before delivery.
